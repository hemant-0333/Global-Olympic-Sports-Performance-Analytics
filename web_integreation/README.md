# Global Olympic Sports Performance Analytics (1992–2026)

## 📌 Project Overview
**Global Olympic Sports Performance Analysis** is an interactive data analytics and visualization project built using **Tableau Public** and integrated into a **Python Flask** web application.

## 🚀 How to Run Locally
1. Install Flask: `py -m pip install flask`
2. Run the Flask server: `py app.py` (or double-click `Start_Website.bat`)
3. Open your browser and visit: `http://127.0.0.1:8000/`
